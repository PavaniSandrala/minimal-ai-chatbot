# 🤖 Minimal AI Chatbot

A simple AI chatbot built using Streamlit, LangChain and Groq.

## 🚀 Technologies Used

- Python
- Streamlit
- LangChain
- Groq API

## ✨ Features

- Interactive chat interface
- Maintains conversation history
- AI-powered responses
- Deployed using Streamlit Community Cloud
